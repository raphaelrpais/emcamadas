# 🖨️ em camadas

> Portfólio pessoal de impressão 3D — e destino dos links NFC embutidos nos projetos físicos.

**[emcamadas.com](https://emcamadas.com)**

---

## ✨ O que é

Portfólio de modelos impressos em 3D. Cada projeto tem sua própria página com fotos, ficha técnica e configurações de impressão — e alguns modelos físicos têm tags NFC embutidas que apontam direto para essas páginas.

---

## 🛠️ Stack

| Camada | Tecnologia |
|---|---|
| Markup | HTML5 |
| Estilo | CSS3 |
| Interatividade | JavaScript |
| Hospedagem | GitHub Pages |
| Domínio | `emcamadas.com` |
| Deploy | GitHub Actions |

---

## 💡 Por que "em camadas"?

Impressão 3D FDM constrói cada objeto camada por camada — o nome é literal.
